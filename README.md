# Unemployment Analysis in India 📊

## Project Overview

This project explores unemployment trends across India using Python and data visualization libraries. It focuses on regional differences, urban and rural unemployment, and changes in unemployment rates during the COVID-19 pandemic.

## Objectives

* Analyze unemployment trends across Indian regions.
* Compare unemployment rates in urban and rural areas.
* Examine monthly unemployment trends during 2020.
* Investigate the impact of the COVID-19 period on unemployment.
* Visualize patterns and relationships in the dataset.

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

The project uses an Indian unemployment dataset containing regional and time-based information, including:

* Region
* Date
* Estimated Unemployment Rate (%)
* Estimated Employed
* Estimated Labour Participation Rate (%)
* Area (Urban/Rural)

The dataset also includes geographical information for regional analysis.

## Project Workflow

1. Load the dataset into Pandas.
2. Inspect the dataset's shape, columns, data types, and missing values.
3. Clean column names and convert dates to the appropriate format.
4. Explore unemployment patterns across regions.
5. Compare urban and rural unemployment rates.
6. Analyze monthly trends during 2020.
7. Compare unemployment before and during the COVID-19 period.
8. Visualize findings using Matplotlib and Seaborn.

## Key Findings

* Average unemployment was higher in urban areas than in rural areas in the analyzed dataset.
* The average unemployment rate increased during the COVID-19 period compared with the pre-COVID period.
* April and May 2020 showed particularly high monthly average unemployment rates.
* Haryana, Tripura, and Jharkhand were among the regions with the highest average unemployment rates in the analysis.

### Selected Results

* Average rural unemployment rate: approximately 10.32%
* Average urban unemployment rate: approximately 13.17%
* Average pre-COVID unemployment rate: approximately 9.76%
* Average unemployment rate during the analyzed COVID-19 period: approximately 13.28%

Note: These figures are calculated from the dataset and period used in this project. They should not be interpreted as current unemployment statistics for India.

## How to Run the Project

1. Clone or download this repository.

2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

3. Ensure the dataset CSV file is available at the path referenced in the notebook.

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the notebook and run the cells in order.
